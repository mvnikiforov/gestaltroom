## Что это

Одностраничный статический сайт-визитка двух гештальт-терапевтов (Мария, Валерия).
Домен `https://gestalt-room.ru`, город Чебоксары. Бэкенда нет, всё собирается в `dist/`.

Стек: React 18 + TypeScript (`strict`), Vite 6 (порт 3000, `strictPort`), Tailwind CSS 4,
ESLint 10 (flat config). Node 18+.

## Главные правила

- **Весь контент сайта — только в `src/data/psychologists.ts`.** Тексты, имена, телефоны,
  фото, цвета карточек, шапка/подвал (`site`), блок «Быстрый старт» (`quickStart`).
  Второго файла с контентом не заводить.
- **Tailwind 4 — CSS-first:** тема в блоке `@theme` файла `src/index.css`.
  `tailwind.config.js` не существует и создавать его не нужно.
- **Не ломать архитектурные особенности** (flip-карточка, отдельный скролл биографии,
  grid на `lg`, a11y-синхронизация `aria-hidden`/`tabIndex`, `prefers-reduced-motion`) —
  полный список с объяснениями в `project.md`, раздел «Архитектурные особенности».
- **Язык:** тексты сайта, комментарии, сообщения коммитов и артефакты OpenSpec — на русском.
- **Стиль:** отступ 2 пробела; одинарные кавычки в `.ts`/`.tsx`, двойные — в
  `vite.config.js` и `eslint.config.js` (так исторически в файлах). Автоформаттера нет.
- **Фото:** в данных путь от корня сайта (`/images/x.webp`), **без** `public/`, регистр
  важен. Оригиналы — в `photos-source/`, в `dist/` не попадают.

## Команды

```bash
npm install
npm run dev         # http://localhost:3000
npm run build       # typecheck + сборка в dist/
npm run preview     # просмотр dist/ на 3000
npm run typecheck   # tsc --noEmit
npm run lint        # eslint
```

**Перед сдачей любой задачи обязательно прогнать:**
`npm run typecheck && npm run lint && npm run build`.

Тестов в проекте нет — проверка визуальная (`npm run dev` + встроенный браузер),
плюс эти три команды.

## Процесс работы

- **Крупные изменения** (новая секция, редизайн, смена поведения карточек) — через
  OpenSpec в `openspec/`: `propose` → `apply` → `archive`. Артефакты пишутся на русском,
  структурные заголовки и `SHALL`/`MUST` остаются на английском (`openspec/config.yaml`).
- **Мелкие правки** (текст, отступ, цвет) — напрямую, по возможности отдельной веткой.
- **Ветки:** работаем в `feature/*`, `fix/*`, `content/*`; вливаем в `main` через PR.

## Git и деплой

- Текущая ветка `main` синхронизирована с `origin` (`github.com/mvnikiforov/gestaltroom`).
- **Push в `main` = автодеплой на прод**: GitHub Actions собирает проект и выкладывает
  `dist/` по FTP в `/www/gestalt-room.ru/` на reg.ru (секреты `FTP_SERVER`,
  `FTP_USERNAME`, `FTP_PASSWORD`).
- **Никогда не пушить в `main` без явного разрешения пользователя.** PR-ветки деплой
  не запускают — на них только `lint` + `build`.
- Секреты и пароли в репозиторий не добавлять.
