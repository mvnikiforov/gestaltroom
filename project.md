# gestalt-room.ru — заметки для ИИ

Краткая карта проекта для быстрого входа в контекст. Подробные инструкции
для человека — в `README.md`.

## Что это

Одностраничный сайт-визитка для двух гештальт-терапевтов (Мария, Валерия).
Город — Чебоксары, работа онлайн и офлайн. Домен: `https://gestalt-room.ru`.
Полностью статический, бэкенда нет.

## Стек

- React 18 + TypeScript (`strict`)
- Vite 6, порт **3000** (`strictPort`), хост `0.0.0.0`
- Tailwind CSS 4 — CSS-first, тема в блоке `@theme` файла `src/index.css`.
  Файла `tailwind.config.js` нет и создавать не нужно.
- ESLint 10 flat config, `typescript-eslint`, `react-hooks`, `react-refresh`

Шрифты подключены из Google Fonts в `index.html` (Cormorant Garamond, Inter).

## Ключевое правило

**Весь контент — в `src/data/psychologists.ts`.** Тексты, имена, телефоны,
пути к фото, цвета карточек, заголовок и подвал сайта (`site`), а также блок
«Быстрый старт» (`quickStart`). Правки контента делаются только там, второй
файл не нужен.

## Адрес

Под заголовком в шапке — ссылка на Яндекс Карты с иконкой-булавкой, кегль
ровно вдвое меньше `h1` на каждом брейкпоинте (`text-[15px] sm:text-[18px]
md:text-[24px] lg:text-[30px]`). Текст адреса — `site.address`, ссылка
собирается из него же: `mapsUrl = https://yandex.ru/maps/?text=<адрес>&z=17`
(`encodeURIComponent`). При смене адреса правится только `address`, вручную
ничего кодировать не нужно. Ссылка открывается в новой вкладке.

## Быстрый старт

Блок между рядом карточек и подвалом: светлая карточка `rounded-3xl
bg-warm-100` с двумя пунктами (кофе с психологом, практики для успокоения
ума). Вёрстка внутри — вертикальный список `<ol>` с `<dl>`-строками, подписи
«Формат / Когда / Время / Стоимость / Ведущие» заданы в компоненте, значения —
в `quickStart`.
 Кнопок записи внутри нет, только текст. Появления нет: секция
видна сразу, без анимации. На `lg` блок растянут от левого края фото до
правого края фото, на мобильных равен ширине карточки. Заголовок «Быстрый
старт» повторяет eyebrow-строку «Гештальт-терапия» из шапки.


## Архитектурные особенности (не ломать)

- **Flip-карточка** на CSS: `.card-inner` с `transform-style: preserve-3d`,
  `.card-face` с `backface-visibility: hidden`. Оборотная сторона —
  `rotateY(180deg)`. Переворот вешается инлайном через `style`.
- **Клик только по лицевой стороне.** На рубашке (`card-back`) кнопки нет
  намеренно: иначе прокрутка длинной биографии переворачивала бы карточку.
- **Биография скроллится отдельно** (`overflow-y-auto` + `overscroll-contain`),
  телефон и кнопка «вернуться к портрету» — `shrink-0`, всегда видны.
- **Футер карточки — две строки.** Внешний контейнер `shrink-0 flex flex-col
  items-end gap-3 pt-3`: первая строка — «таблетка» телефона, вторая —
  `div flex items-center gap-3` с кнопками мессенджеров и возвратом. `items-end`
  прижимает обе строки к правому краю внутренней области карточки; дефолтный
  `stretch` растянул бы их на всю ширину. Во второй строке кнопки идут в порядке
  данных, возврат — последним. У всех кнопок рамка 1px (у телефона
  `border-transparent`, у остальных `border-current`) и высота 42px: телефон
  даёт её за счёт строки `text-sm` с `py-2.5`, иконко-только кнопки — `py-3`.
  Рамка держит равную высоту, а не выравнивание, поэтому `py-*` или рамку в
  одном элементе без второго не меняют. У возврата только стрелка, доступное
  имя — в `aria-label`, это единственный носитель текста «Вернуться к портрету».
- **Подсказка «есть что дочитать»** — градиент снизу, появляется через
  `ResizeObserver` + обработчик `scroll`, если `scrollHeight > clientHeight`
  и не докручено до конца. Эффект зависит от `isFlipped`.
- **Появление карточек** — CSS-анимации (`reveal-down` / `reveal-up`) и
  `setTimeout` в `useEffect` для `isVisible`. ESLint-правило про `setState`
  в эффектах ругается — это ожидаемо, так и задумано.
- **`prefers-reduced-motion`** уважается в трёх местах: `index.css`
  (`.card-inner`, `.reveal-*`, `.float-animation`), плюс `motion-reduce:`
  у Tailwind-классов в компонентах. Не убирать.
- **a11y:** `aria-hidden` и `tabIndex` на лицевой/оборотной стороне
  синхронизированы с `isFlipped`, чтобы скрытая сторона не попадала
  в фокус и скринридер.
- **Ряд карточек — grid на `lg`:** `lg:grid-cols-[repeat(2,minmax(0,400px))]`
  `lg:gap-x-14`, колонки равны `max-w-[400px]` карточек. Секция «Быстрый
  старт» — третий ребёнок с `lg:col-span-2`, поэтому совпадает по краям
  с фотографиями. Смена ширины колонок сразу сломает выравнивание. На `<lg`
  контейнер — обычный `flex flex-col`, секция ограничена теми же
  `max-w-[340px] / [380px] / [400px]`, что и карточка.
- **Секция «Быстрый старт» статична:** без flip, без `useState` и без
  анимации появления — видна сразу.

## Фотографии

- Файлы берутся из `public/` и отдаются по пути от корня сайта: путь в
  данных начинается с `/`, **без** `public/`. Регистр букв важен (Linux).
- Оригиналы (до сжатия) лежат в `photos-source/` — оттуда они не попадают
  в `dist/` и не уезжают на хостинг.
- Сжатие: `npx --yes sharp-cli@5 -i photo.jpg -o public/images/x.webp -f webp -q 82`
- Формат отображения — `object-cover`, кадрирование по центру, изменить
  одной настройкой нельзя.
- Текущие размеры в данных: Мария 836×1254 (76 КБ), Валерия 708×1061 (32 КБ).
  При замене фото обновить `width`/`height`, иначе браузер неверно
  зарезервирует место до загрузки.

Обе кнопки-канала иконко-только: подпись не выводится, её роль выполняет
`aria-label` из поля `label`; `py-3` держит высоту 42px, как у остальных
«таблеток». Остальные ссылки (если появятся) пока рендерят обычную иконку
paper-plane. Логотипы — товарные знаки, поэтому брать только официальные
версии и не менять пропорции и цвета.

Логотип MAX — товарный знак, поэтому при замене брать только официальные
версии из брендбука, не менять пропорции и цвета. В репозитории
`max-messenger/max-ui` логотипа нет — это библиотека компонентов, а не набор
брендовых ассетов.

## Аналитика

Счётчик Яндекс Метрики подключается в `src/lib/analytics.ts`, вызывается из
`src/main.tsx` до рендера. Номер счётчика берётся из `VITE_YM_ID`:

- локально — скопировать `.env.example` в `.env.local` и указать номер;
- на проде — переменная GitHub Actions `VITE_YM_ID` (Settings → Secrets and
  variables → Actions → Variables), workflow передаёт её в `npm run build`.

Если переменная пустая, аналитика молча отключается — сборка и сайт работают
как обычно. В Метрике нужно создать цели типа «JavaScript-событие».

Общие цели (сумма по карточкам):

- `card_open` — открыли карточку, параметр `psychologist`;
- `phone_click` — клик по телефону, параметр `psychologist`;
- `max_click` — клик по MAX, параметр `psychologist`;
- `telegram_click` — клик по Telegram, параметр `psychologist`;
- `messenger_click` — резервная цель для ссылок, которые не распознаны как MAX
  или Telegram, параметры `psychologist`, `messenger`;
- `map_click` — клик по адресу в шапке;
- `quick_start_view` — блок «Быстрый старт» показался во viewport.

Отдельные цели по карточкам называются `<id психолога>_<действие>` и уходят
вместе с общей целью:

- Валерия: `valeriya_card_open`, `valeriya_phone_click`,
  `valeriya_max_click`, `valeriya_telegram_click`;
- Мария: `mariya_card_open`, `mariya_phone_click`, `mariya_telegram_click`.

У Марии нет ссылки на MAX, поэтому цели `mariya_max_click` нет. Имена целей
собираются из `id` в данных, так что новому психологу достаточно задать свой
`id` — набор целей будет таким же.

Персональные данные в события не передаются — только id специалиста и тип
канала.
