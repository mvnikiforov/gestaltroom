# gestalt-room.ru — заметки для ИИ

Краткая карта проекта для быстрого входа в контекст. Подробные инструкции
для человека — в `README.md`.

## Что это

Одностраничный сайт-визитка для двух гештальт-терапевтов (Мария, Валерия).
Город — Чебоксары, работа онлайн и офлайн. Домен: `https://gestalt-room.ru`.
Полностью статический, бэкенда нет.

## Стек

- React 18 + TypeScript (`strict`)
- Vite 6, порт **3000** (`strictPort`), хост `0.0.0.0`
- Tailwind CSS 4 — CSS-first, тема в блоке `@theme` файла `src/index.css`.
  Файла `tailwind.config.js` нет и создавать не нужно.
- ESLint 10 flat config, `typescript-eslint`, `react-hooks`, `react-refresh`

Шрифты подключены из Google Fonts в `index.html` (Cormorant Garamond, Inter).

## Ключевое правило

**Весь контент — в `src/data/psychologists.ts`.** Тексты, имена, телефоны,
пути к фото, цвета карточек, заголовок и подвал сайта (`site`), а также блок
«Быстрый старт» (`quickStart`). Правки контента делаются только там, второй
файл не нужен.

## Быстрый старт

Блок между шапкой и портретами: карточка `rounded-3xl bg-olive-500`
(золотисто-оливковый `#ad9742`, токен `--color-olive-500` в `@theme`) с двумя
пунктами (кофе с психологом, практики для успокоения ума). Вёрстка внутри —
вертикальный список `<ol>` с `<dl>`-строками, подписи «Формат / Когда / Время /
Стоимость» заданы в компоненте, значения — в `quickStart`. Кнопок записи
внутри нет, только текст. Появление — CSS-класс `reveal-up`, а не JS-таймер.
На `lg` блок растянут от левого края фото до правого края фото, на мобильных
равен ширине карточки. Заголовок «Быстрый старт» повторяет eyebrow-строку
«Гештальт-терапия» из шапки.

Текст внутри тёмный (`text-warm-900` / `text-warm-800`), а не светлый: на
`#ad9742` белый даёт контраст ~2.9:1 и не проходит WCAG AA, тёмно-коричневый
даёт ~5.5:1.

## Архитектурные особенности (не ломать)

- **Flip-карточка** на CSS: `.card-inner` с `transform-style: preserve-3d`,
  `.card-face` с `backface-visibility: hidden`. Оборотная сторона —
  `rotateY(180deg)`. Переворот вешается инлайном через `style`.
- **Клик только по лицевой стороне.** На рубашке (`card-back`) кнопки нет
  намеренно: иначе прокрутка длинной биографии переворачивала бы карточку.
- **Биография скроллится отдельно** (`overflow-y-auto` + `overscroll-contain`),
  телефон и кнопка «вернуться к портрету» — `shrink-0`, всегда видны.
- **Подсказка «есть что дочитать»** — градиент снизу, появляется через
  `ResizeObserver` + обработчик `scroll`, если `scrollHeight > clientHeight`
  и не докручено до конца. Эффект зависит от `isFlipped`.
- **Появление карточек** — CSS-анимации (`reveal-down` / `reveal-up`) и
  `setTimeout` в `useEffect` для `isVisible`. ESLint-правило про `setState`
  в эффектах ругается — это ожидаемо, так и задумано.
- **`prefers-reduced-motion`** уважается в трёх местах: `index.css`
  (`.card-inner`, `.reveal-*`, `.float-animation`), плюс `motion-reduce:`
  у Tailwind-классов в компонентах. Не убирать.
- **a11y:** `aria-hidden` и `tabIndex` на лицевой/оборотной стороне
  синхронизированы с `isFlipped`, чтобы скрытая сторона не попадала
  в фокус и скринридер.
- **Ряд карточек — grid на `lg`:** `lg:grid-cols-[repeat(2,minmax(0,400px))]`
  `lg:gap-x-14`, колонки равны `max-w-[400px]` карточек. Секция «Быстрый
  старт» — первый ребёнок с `lg:col-span-2`, поэтому занимает всю ширину
  ровно по краям фотографий, а карточки автоматически встают во вторую
  строку. Смена ширины колонок сразу сломает выравнивание. На `<lg`
  контейнер — обычный `flex flex-col`, секция идёт первой и ограничена
  теми же `max-w-[340px] / [380px] / [400px]`, что и карточка.
- **Секция «Быстрый старт» статична:** без flip и без `useState`, появление
  через CSS-класс `reveal-up`.
- **Подсказка «нажмите на портрет»** осталась в шапке, хотя под стрелкой
  теперь карточка «Быстрый старт» — если смущает, перенести под карточку.

## Фотографии

- Файлы берутся из `public/` и отдаются по пути от корня сайта: путь в
  данных начинается с `/`, **без** `public/`. Регистр букв важен (Linux).
- Оригиналы (до сжатия) лежат в `photos-source/` — оттуда они не попадают
  в `dist/` и не уезжают на хостинг.
- Сжатие: `npx --yes sharp-cli@5 -i photo.jpg -o public/images/x.webp -f webp -q 82`
- Формат отображения — `object-cover`, кадрирование по центру, изменить
  одной настройкой нельзя.
- Текущие размеры в данных: Мария 836×1254 (76 КБ), Валерия 708×1061 (32 КБ).
  При замене фото обновить `width`/`height`, иначе браузер неверно
  зарезервирует место до загрузки.

## Команды

```bash
npm install
npm run dev         # http://localhost:3000
npm run build       # typecheck + сборка в dist/
npm run preview     # просмотр dist/ на 3000
npm run typecheck   # tsc --noEmit
npm run lint        # eslint
```

Перед завершением задачи прогонять `npm run typecheck`, `npm run lint`
и `npm run build`. Линтер-скрипта форматирования нет — отступы 2 пробела,
одинарные кавычки в JS/TS, в `vite.config.js` и `eslint.config.js`
двойные (так в файлах изначально).

## Деплой

GitHub Actions `.github/workflows/main.yml`: push в `main` → `npm ci` →
`npm run build` → FTP на reg.ru, каталог `/www/gestalt-room.ru/`.
Секреты в GitHub: `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`.

SEO-мета-теги и `og:image` с **абсолютным** URL — в `index.html`.
При смене домена поправить `og:image`, `og:url` и мета-описания
(там же живёт город — сейчас Чебоксары; раньше был Москва, уже забыто
в одной ревизии).

## Известные мелочи

- У Валерии в `bio` есть эмодзи `🌺` — намеренно, так пишет она сама.
- Биография Валерии заметно длиннее (8 абзацев), поэтому карточка у неё
  всегда показывает подсказку «есть что дочитать».
- `accent` и `fade` в данных должны быть согласованы: `fade` — цвет фона
  из `accent`, иначе градиент-подсказка видна как тёмное пятно.
